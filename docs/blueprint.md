# **App Name**: CaptionWise

## Core Features:

- Image Upload: Users can upload images directly from their device.
- Caption Suggestion: Generative AI will analyze the uploaded image and suggest several relevant captions.
- Caption Refinement: The tool will allow users to refine caption suggestions.
- Caption Display: Display suggested captions clearly below the uploaded image.
- Caption Copy: Users can copy captions to their clipboard for easy posting.
- Theme Switch: App appearance can be switched between light and dark mode.

## Style Guidelines:

- Primary color: Soft, calming blue (#64B5F6) to evoke a sense of creativity and inspiration, reflecting the caption generation aspect of the app. The selection of blue reflects trustworthiness.
- Background color: Light gray (#F0F4F8), providing a neutral backdrop that ensures the uploaded images and generated captions stand out without distraction.
- Accent color: A gentle teal (#4DB6AC) for interactive elements like buttons, which draws inspiration from social media color palettes.
- Clean and modern font.
- Simple and intuitive icons.
- Clean and simple design.
