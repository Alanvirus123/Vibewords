# VibeWords: AI-Powered Creator Suite

VibeWords is a premium Next.js application designed for modern creators to generate social media content, cinematic videos, and audio vibes.

## 🚀 Getting Started
1. Open the project in your IDE.
2. Run `npm run dev` to start the local Vibespace.
3. Navigate to `http://localhost:3000`.

## 🛠 Features
- **Vibespace**: Dynamic content generation engine.
- **The Stash**: Persistent cloud history for your creative assets.
- **Cinematic Morph**: Static-to-video animation via Veo.
- **Command Shell**: High-speed navigation via `Cmd+K`.
- **Live Preview**: See your content exactly as it appears on social platforms.
